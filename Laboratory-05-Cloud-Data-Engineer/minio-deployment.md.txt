# MinIO Object Storage Deployment

## Docker Command Used

docker run -d -p 9000:9000 -p 9001:9001 --name minio-server -e "MINIO_ROOT_USER=cloudadmin" -e "MINIO_ROOT_PASSWORD=CloudNova2026!" minio/minio server /data --console-address ":9001"

## Web Console Port
Port 9001

## Bucket Created
client-photos

## What the -e Flags Do

The -e flags set environment variables inside the container:
- MINIO_ROOT_USER=cloudadmin — sets the admin username
- MINIO_ROOT_PASSWORD=CloudNova2026! — sets the admin password
