# Laboratory 05 — The Cloud Data Engineer

## Mission Overview
In this mission, I acted as a Cloud Data Engineer at CloudNova Technologies. I deployed MinIO, an S3-compatible object storage server, using Docker inside a KillerCoda Ubuntu playground. I accessed the web console via port forwarding, created a bucket named client-photos, and uploaded a test file.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server (MinIO) using Docker.
- Access a cloud service via a web interface using port forwarding.
- Create a storage bucket and upload objects.
- Document cloud storage operations using Markdown.

## Tools Used
- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Markdown

## Skills Learned
- Differences between block, file, and object storage.
- Deploying containerized services with Docker.
- Port forwarding to access a cloud service.
- Creating and managing storage buckets.
- Writing technical documentation in Markdown.
