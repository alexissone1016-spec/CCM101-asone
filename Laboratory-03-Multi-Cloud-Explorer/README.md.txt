# Mission 3 — Multi-Cloud Explorer

## Mission Overview

This laboratory activity focuses on exploring the three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The mission involves researching each platform, comparing their services, and recommending the best provider for different business scenarios.

## Objectives

- Explore the major public cloud platforms
- Identify core services offered by AWS, Azure, and GCP
- Compare cloud services across different providers
- Analyze business requirements and recommend appropriate cloud solutions
- Create professional technical documentation using Markdown

## Cloud Platforms Researched

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

## Tools Used

- GitHub
- Markdown
- Web Browser
- Official Cloud Documentation

## Skills Learned

- Cloud platform research and analysis
- Service comparison across multiple providers
- Client needs assessment
- Technical documentation using Markdown
- GitHub portfolio management

## Linux Server Cloud Hosting

### Operating System

The Linux server used in KillerCoda runs Ubuntu 24.04.4 LTS.

### CPU Information

The server has 1 CPU core running an Intel Xeon E312xx processor.

### Memory

The server has approximately 1.9 GiB of RAM.

### Disk Space

The server has 19 GB of disk storage with 13 GB available.

### Cloud Hosting Options

This Linux server could be hosted using equivalent virtual machine services:

| AWS | Azure | GCP |
|---|---|---|
| Amazon EC2 | Azure Virtual Machines | Compute Engine |

## Challenges Encountered

One challenge was comparing equivalent services across the three platforms, as they use different naming conventions. Another challenge was understanding how business requirements translate into specific platform recommendations.
