# Cloud Provider Comparison

## Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering computing, storage, databases, networking, security, analytics, and many other areas. It is widely used by organizations with different types of workloads and has the most extensive global infrastructure.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a strong choice for an organization that primarily uses Microsoft products. Azure integrates closely with Microsoft technologies such as Windows Server, Microsoft Entra ID, Microsoft 365, and other Microsoft enterprise services, providing seamless hybrid cloud capabilities.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud is widely recognized for its strengths in Artificial Intelligence, Machine Learning, and Kubernetes. Google also developed Kubernetes, making Google Cloud a strong platform for containerized applications and AI/ML workloads with tools like TensorFlow and Vertex AI.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer similar fundamental cloud infrastructure services including compute, storage, networking, and identity and access management. They also provide global data centers, pay-as-you-go pricing models, and similar security and compliance features, although the names and implementation details are different.
